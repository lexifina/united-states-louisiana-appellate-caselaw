# State v. Gantt

## Majority (WRIT DENIED.)

WRIT DENIED.
There is no error in the trial court’s ruling. Relator’s remedy lies in a claim against the local indigent defender board from any funds received pursuant to La. R.S. 15:146. Knickerbocker v. Vermilion Parish Police Jury, 371 So.2d 1298 (La. App. 3 Cir.1979).
