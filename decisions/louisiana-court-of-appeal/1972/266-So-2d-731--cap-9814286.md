# In re State ex rel. Jenkins

## Majority (MILLER, Judge.)

MILLER, Judge.
The facts and issues of this case are almost identical to State In Interest of Aaron, 266 So.2d 726 (Docket No. 3960 handed down this date).
For the reasons assigned in that opinion, the commitment of Commodore Jenkins to the Louisiana Training Institute is set aside and the cause remanded for further proceedings.
Commitment set aside: case remanded.

## Dissent (DOMENGEAUX, J.,)

DOMENGEAUX, J.,
dissents for the same reasons assigned in his dissenting opinion in our docket #3960, 266 So.2d 726.
